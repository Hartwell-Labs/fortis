Why fortis

What it does, concretely.

Measured boot, for real

A full SHA-256 implementation on bare metal — not a stub calling out to a host.

Post-quantum ready

ML-KEM-768 in the attestation path, so chains verified today stay verifiable later.

Bare-metal Rust

No OS underneath: the trust root is the code you audit, nothing else.

Reproducible on QEMU

The whole boot chain runs on QEMU virt — testable anywhere, deterministically.
